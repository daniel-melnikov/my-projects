# Автоматизация расчетов ключевых метрик Яндекс Такси

[Ссылка на проект](https://github.com/daniel-melnikov/my-projects/blob/main/Автоматизация%20расчетов%20ключевы%20метрик%20Яндекс%20Такси/Автоматизация%20аналитических%20процессов%20Яндекс%20Такси.ipynb)

## Описание проекта
**Цель проекта** — построить витрину данных, которая будет агрегировать информацию о поездках по каждому способу оплаты.

## Результаты:
- написан Spark-скрипт с помощью PySpark, который агрегирует данные по способу оплаты и рассчитывает ключевые метрики, а затем записывает их в таблицу в Clickhouse;
- создан DAG для Airflow, который ежедневно ждет появления данных в S3, а затем запускает Spark-скрипт.
