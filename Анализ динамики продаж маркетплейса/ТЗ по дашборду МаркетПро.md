## 3. Показатели / метрики

| № | Название показателя | Логика расчёта | Источник данных | Комментарий | Категория метрики |
|---|---------------------|---------------|-----------------|-------------|-------------------|
| | GMV (Gross Merchandise Value) | `COALESCE(SUM(total_amount), 0)` | marketplace.orders | Общая выручка | Базовые |
| | Количество заказов | `COALESCE(COUNT(DISTINCT order_id), 0)` | marketplace.orders | | Базовые |
| | Количество продавцов | `COALESCE(COUNT(DISTINCT user_id), 0)` <br> где `user_type = 'buyer'` | marketplace.users | | Базовые |
| | Количество покупателей | `COALESCE(COUNT(DISTINCT user_id), 0)` <br> где `user_type = 'seller'` | marketplace.users | | Базовые |
| | Конверсия | `COUNT(DISTINCT o.buyer_id) / COUNT(DISTINCT u.user_id)` | marketplace.users + marketplace.orders | Доля пользователей, совершающих покупки | Производные |
| | Средний чек | `SUM(total_amount) / COUNT(order_id)` | marketplace.orders | Выручка на кол-во заказов | Производные |
| | Кол-во позиций в заказе | `ROUND(AVG(SUM(quantity)), 2)` по order_id | marketplace.order_items | Среднее кол-во позиций в корзине | Производные |
| | Retention Rate | Кол-во пользователей, сделавших заказ в первый месяц после регистрации | marketplace.users + marketplace.orders | | Производные |
| 1.0 | Кол-во отзывов | `COALESCE(COUNT(DISTINCT review_id), 0)` <br> где `comment` не пустой | marketplace.reviews | Активность пользователей в оставлении отзывов | Базовые |
| 2.0 | Средний рейтинг | `ROUND(AVG(rating), 2)` | marketplace.reviews | Удовлетворенность пользователей | Базовые |
| | LTV | Выручка за 3 мес / кол-во пользователей в когорте | marketplace.users + marketplace.orders | Удовлетворенность пользователей | Базовые |
| | ARPU | Суммарная выручка / число активных пользователей | marketplace.orders | Удовлетворенность пользователей | Базовые |
| | ARPPU | Суммарная выручка / число платящих пользователей | marketplace.orders | Удовлетворенность пользователей | Базовые |
| | DAU | `COUNT(DISTINCT buyer_id)` по дням | marketplace.orders | Удовлетворенность пользователей | Базовые |

## 5. Визуализации

### Вкладка «Продажи»

| № | График | Комментарий | Пример |
|---|--------|-------------|--------|
| 1.0 | Общая выручка (GMV) | Big Number with Trendline | Общая выручка за период + изменение по месяцам и сравнение с предыдущим периодом |
| 2.0 | Общее количество заказов | Big Number with Trendline | Количество заказов за период + изменение по месяцам и сравнение с предыдущим периодом |
| 3.0 | Средний чек | Big Number | Изменение среднего чека отражает поведение покупателей |
| | ARPU | Line Chart | Изменение среднего дохода на одного пользователя |
| | ARPPU | Line Chart | Изменение среднего дохода на одного пользователя, совершившего хотя бы один заказ |
| 4.0 | Среднее количество товаров в заказе | Big Number with Trendline | Изменение метрики показывает степень взаимодействия покупателя с продуктом в рамках одной сделки |
| 5.0 | Средний рейтинг | Big Number with Trendline | Изменение метрики говорит о качестве товаров |
