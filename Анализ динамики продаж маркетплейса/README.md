# Анализ динамики продаж маркетплейса

Ссылки на вкладки дашборда: [Продажи](https://github.com/daniel-melnikov/my-projects/blob/main/Анализ%20динамики%20продаж%20маркетплейса/Продажи.png), [Пользователи](https://github.com/daniel-melnikov/my-projects/blob/main/Анализ%20динамики%20продаж%20маркетплейса/Пользователи.png)

## Описание проекта:

Руководитель маркетплейса отправил запрос на создание обзорного дашборда по ключевым метрикам платформы. Главные требования к дашборду: наглядность и оперативность.

## Результаты:

- Проведено интервью с заказчиком с целью сбора требования к дашборду, сформулировано ТЗ;
- Проведена [предобработка данных](https://github.com/daniel-melnikov/my-projects/blob/main/Анализ%20динамики%20продаж%20маркетплейса/Предобработка%20данных%20МаркетПро.ipynb);
- Собраны два датасета, на которых построен дашборд;
- Создан дашборд;
- Написана инструкция по обучению пользователей;
