| Категория | Что описать | Пример / Подсказка |
|---|---|---|
| Фильтр | Дата | Фильтр по дате позволяет выбрать нужный период, обновляются все графики |
| Фильтр | Категория товара | Возможность просмотра KPI по категориям товара, распространяется на чарты “Общая выручка”, “Средний чек”, “Количество заказов”, “Количество товаров в заказе”, “Средний рейтинг”, “Количество продавцов”, “Количество покупателей”, “Количество отзывов”. |
| Фильтр | Статус заказа | Возможность просмотра дашборда по конкретному статусу заказа. Распространяется аналогично фильтру “Категория товара” |
| Фильтр | Рейтинг | Возможность анализировать дашборд по рейтингу товаров. Распространяется аналогично фильтру “Категория товара” |
| Метрика | Средний чек | Средний чек показывает, сколько в среднем тратит пользователь за заказ |
| Метрика | Средний рейтинг | Показывает средний рейтинг товара, основанный на оценке пользователей |
| Метрика | ARPU | Показывает сколько выручки приносит один пользователь |
| Метрика | ARPPU | Показывает сколько выручки приносит один пользователь, совершивший хотя бы один заказ |
| Метрика | Конверсия | Показывает долю пользователей, совершивших заказ, от всех пользователей |
| Метрика | DAU | Показывает количество активных пользователей по дням |
| Метрика | LTV | Показывает срок жизни пользователя в рамках маркетплейса. Рассчитывается как Выручка за 3 мес / кол-во пользователей в когорте |
| Метрика | Retention Rate | Показывает сколько пользователей совершили заказ в течение первого месяца с момента регистрации |
| График | Общая выручка | Если выручка растет, значит бизнес стремится к прибыльности, если падает, значит бизнес может нести убытки |
| График | Количество заказов | Чем больше заказов, тем больше выручка |
| График | Среднее количество товаров в заказе | Если показатель высокий, значит, пользователь готов/способен закрыть несколько своих потребностей, благодаря продукту. Низкий показатель говорит о недоверии пользователей к продукту |
| График | Средний чек | Средний чек показывает, сколько в среднем тратит пользователь за заказ |
| График | Средний рейтинг | Сигнализирует об удовлетворенности пользователей качеством товаров |
| График | ARPU и ARPPU | Сравните ARPU и ARPPU за несколько месяцев. Если показатель снижается, проверьте одновременно конверсию и количество покупателей, чтобы понять, связано ли падение с уменьшением покупательской активности |
| График | Количество продавцов и покупателей | Демонстрируют баланс спроса и предложения |
| График | Конверсия | Чем выше конверсия, тем больше пользователи удовлетворены продуктов и готовы совершать заказы |
| График | DAU | Чем активнее пользователи, тем больше заказов они совершают |
| График | Количество отзывов | Малое количество отзывов может свидетельствовать о затрудненном сборе обратной связи или низкой мотивации пользователей в оставлении отзывов |
| График | LTV | Средняя ценность пользователя за период, сигнализирует об уровне удовлетворенности пользователей |
| График | Retention Rate | Показывает долю пользователей, совершивших свой первый заказ в течение месяца после регистрации, в разрезе месячных когорт |
| Сигналы / аномалии | Рост выручки на фоне оттока пользователей | Есть риск падения выручки |
| Сигналы / аномалии | Падение LTV в последние 2 месяца | Есть риск резкого снижения удержания пользователей |
| Сигналы / аномалии | Малое количество отзывов и низкий рейтинг товаров | Предположительно, превалируют негативные отзывы и оценки, а положительные пользователи ставят и пишут неактивно |
